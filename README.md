## 🔍 Sobre o Projeto
O **EVA OSINT** é um ecossistema avançado de investigação digital. São 11 módulos.
- **Nick**: retorna +50 redes sociais (com ID, foto, bio), faz osint no Google com Dorks, relatório automatizado.
- **ID**: retorna ids, fotos, bio, seguidores, metadados de perfis em +7 redes sociais.
- **Cpf/Cnpj**: retorna origem de emissão do cpf, dados cadastrais, estrutura e quadro societário.
- **Tel**: mostra WhatsApp, conta no Telegram, dados cadastrais, identifica operadora.
- **Nome**: retorna dados cadastrais, faz Osint com IA.
- **Email**: retorna dados cadastrais.
- **Site**: mostra print do site, whois, reputação, mapea a infraestrutura, tecnologias, DNS, portas abertas.
- **Vazamentos**: rastrea exposições de credenciais no Intelx e Alientxtbase. 
- **Wallet**: rastrea transações e saldo.
- **Image**: realiza busca por imagem, trás resultados visuais e relatório automatizado com IA.
